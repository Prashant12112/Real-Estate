A comprehensive **Real Estate Analytics, Price Prediction, and Apartment Recommendation Platform** for **Gurgaon**, built using **Machine Learning, Data Analysis, and Streamlit**.

This project helps users to:
- Predict property prices
- Analyze real estate market trends
- Visualize sector-wise prices on interactive maps
- Get apartment recommendations based on location and preferences



## 📌 Project Overview

The **Gurgaon Real Estate Intelligence Platform** leverages historical property data and machine learning models to assist buyers, investors, and analysts in making **data-driven real estate decisions**.

It integrates:
- Machine Learning based price prediction  
- Interactive market analytics  
- Geospatial visualization  
- Apartment recommendation system  

---

## 🚀 Features

### 🔮 Property Price Prediction
Predicts an estimated **price range** based on:
- Property Type (Flat / House)  
- Sector / Location  
- Bedrooms (BHK)  
- Bathrooms & Balconies  
- Built-up Area  
- Property Age  
- Furnishing Type  
- Luxury Category  
- Floor Category  
- Servant Room & Store Room availability  

---

### 📊 Real Estate Market Analysis
- Sector-wise **price per square foot**
- Interactive **Geo Map visualization**
- Area vs Price relationship
- BHK-wise price comparison
- Distribution plots by property type
- Feature importance visualization using **WordCloud**

---

### 🏢 Apartment Recommendation System
- Location-based apartment recommendations  
- Landmark-based search  
- Radius-based filtering (in kilometers)  
- Nearby apartment suggestions
